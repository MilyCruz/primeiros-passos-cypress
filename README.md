# My Cypress Automation-

This project utilizes Cypress to automate the testing of a login feature and user update feature. Cypress is a JavaScript based end-to-end testing framework that allows developersto write tests and execute them in a real browser.

## Installation
```bash
npm install
```

> **NOTE:**
>
> it is necesary to have **node** installed

## Running
```bash
# You open the Cypress UI
npx cypress open

# Running the automation by comand line
npx cypress run
```
